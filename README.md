# Домашнее задание 1

## Тема

Нужно реализовать учебный сервис оценки стоимости квадратного метра квартиры.

## Что должно делать приложение

Пользователь вводит параметры квартиры:
- этаж
- количество этажей в доме
- количество комнат в квартире
- площадь квартиры
- жилая площадь квартиры

После отправки формы сервис должен вернуть:
- стоимость квадратного метра
