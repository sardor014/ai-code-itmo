# Тестовая модель и Тест-дизайн

## Тестовая модель
Тестирование разделено на уровни (пирамида тестирования):
1. **Unit-тесты (pytest):** Тестирование моковой логики расчета и функций валидации.
2. **Integration-тесты (pytest):** Проверка API-ендпоинтов (HTTP-запросы и ответы).
3. **E2E-тесты (Playwright):** Имитация действий пользователя в браузере (заполнение формы, отправка, проверка UI).

## Тест-дизайн сценариев (Параметры квартиры)

### Позитивные сценарии
1. **Стандартная квартира:** Ввод всех валидных параметров (например: этаж 5, этажность 10, комнат 2, общая 50, жилая 30).
2. **Граничные значения:**
   - Этаж = 1 (первый этаж).
   - Этаж = Этажность (последний этаж).

### Негативные сценарии
1. **Некорректный этаж:** Этаж больше количества этажей в доме.
2. **Отрицательные значения:** Отрицательная площадь (общая или жилая), отрицательное количество комнат/этажей.
3. **Нулевые значения:** Площадь = 0, количество этажей = 0, количество комнат = 0.
4. **Нелогичная площадь:** Жилая площадь больше или равна общей площади.
5. **Невалидные данные:** Отправка пустых полей, текста или спецсимволов вместо чисел.
