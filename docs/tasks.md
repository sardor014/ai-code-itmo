# Декомпозиция задач

1. **Инициализация**
   - Создать структуру папок (`backend/`, `frontend/`, `tests/`).
   - Настроить task-файл (например, `Taskfile` или `Makefile`) для управления.

2. **Backend (API и логика)**
   - Поднять базовое приложение (FastAPI/Flask).
   - Написать моковый сервис расчета стоимости (эвристика).
   - Реализовать API эндпоинт и валидацию входящих параметров.

3. **Frontend (UI)**
   - Сверстать HTML-форму для ввода параметров.
   - Написать логику отправки формы (fetch) и отображения результата/ошибок.

4. **Тестирование**
   - Написать unit и api тесты на `pytest`.
   - Настроить `Playwright` и написать базовый E2E сценарий.
   - Подключить генерацию отчетов `Allure`.
   - Добавить команды запуска тестов в task-файл.
