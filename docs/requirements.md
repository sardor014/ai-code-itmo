# Требования к сервису оценки стоимости недвижимости

## Функциональные требования
- Пользователь должен иметь возможность вводить следующие параметры квартиры:
  - Этаж
  - Количество этажей в доме
  - Количество комнат в квартире
  - Площадь квартиры (общая)
  - Жилая площадь квартиры
- Сервис должен валидировать введенные данные (например, этаж не может быть больше количества этажей).
- При отправке формы сервис должен рассчитывать (на данном этапе - эвристически/замокировано) и отображать стоимость квадратного метра квартиры.

## Нефункциональные требования
- **Разделение слоев:** Строгое разделение на Backend (API) и Frontend (UI).
- **Масштабируемость:** Архитектура должна позволять бесшовную интеграцию настоящей ML-модели, внешних API и базы данных в будущем (Clean Architecture).
- **Тестируемость:** Приложение должно быть покрыто тестами (e2e с Playwright, API/Unit с pytest) и генерировать отчеты в Allure.
- **Инфраструктура:** Управление запуском проекта и тестов должно осуществляться через task-файл.
